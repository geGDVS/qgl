# 全攻略测试网站（SEWT）
当前版本：v2.6.2

这是一个用于考察用户对高考英语词汇全攻略中中文所对应英文单词、短语和句子掌握情况的网站。

## 功能特点
1. **多样化考察**：可考察单词、短语和句子，在考察短语和句子时会显示重点考察单词，考察单词时会提示首字母。
2. **便捷操作**：支持通过键盘快捷键快速操作（`S` 键显示答案，`N` 键切换下一题，`F` 键添加错题），按钮上的快捷键字母带有下划线提示。
3. **灵活切换**：可通过左上角下拉菜单选择不同范围的单词集进行测试。
4. **个性化设置**：支持切换深色/浅色模式，可开启/关闭操作音效。
5. **错题管理**：支持添加和管理错题集，便于后续重点复习。
6. **自定义拓展**：支持用户自行编写并提交单词集，丰富测试内容。

## 版本说明

### 标准模式 (index.html)
完整的SEWT测试模式，包含全部313页内容和期中期末测试。

### 复习模式 (index2.html) - Review Mode
以15页为一集的二次复习模式，帮助用户进行分阶段复习。

## 使用方法

### 基本操作
1. 打开 `index.html` 或 `index2.html` 文件，即可开始测试（或在线访问 [https://qgl.pages.dev/](https://qgl.pages.dev/)）。
2. 查看显示的中文内容、考察类型及提示信息：
   - 短语和句子会显示重点关键词
   - 单词会显示首字母提示
3. 操作方式：
   - 点击 `SHOW ANS` 按钮或按 `S` 键查看正确答案
   - 点击 `NEXT` 按钮或按 `N` 键切换到下一个题目
   - 点击"加入错题"按钮或按 `F` 键（答案显示后）将题目加入错题集 **（仅适用于复习模式）**
4. 切换单词集：通过左上角下拉菜单选择不同范围的单词集
5. 模式设置：右下角可切换深色/浅色模式和控制音效开关

### 错题集管理
1. **添加错题**：答案显示后，点击"加入错题"按钮或按 `F` 键将当前题目保存
2. **查看错题**：点击左上角的"Wrong Set"按钮进入错题集页面
3. **编辑错题**：在错题集页面可按题集筛选、查看答案或删除题目
4. **数据保存**：错题集自动保存在浏览器本地存储，不需手动保存

### 快捷键一览

| 按键 | 功能 |
|-----|------|
| S | 显示答案 |
| N | 下一题 |
| F | 加入错题（需先显示答案） |

### 自定义单词集
点击 "自定义单词集" 按钮查看编写和提交指南

## 单词集编写指南
（在线访问：[https://qgl.pages.dev/guide](https://qgl.pages.dev/guide)）
1. 使用任意文本编辑工具编写，每行格式：`中文|英文|类型|关键词`
2. 保存为 `.txt` 格式文件
3. 发送邮件至 `blaze_awa@163.com` 提交（主题注明 "单词集提交"）

示例：
```
n.苹果|apple|单词|
去公园|go to the park|短语|go
我喜欢读书。|I like reading books|句子|like
```
